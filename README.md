# ✈️ AeroTransit

> A full-stack web application developed collaboratively as part of our Software Engineering studies.

AeroTransit is a collaborative project built with **React.js** and **Laravel**, combining a modern frontend with a backend API to create a complete full-stack application.

The project gave us practical experience working across the entire development process — from building user interfaces and connecting frontend components to backend APIs, to handling data and collaborating through Git and GitHub.

## 📚 What We Learned

Working on AeroTransit helped us move beyond individual programming exercises and understand how different parts of a real application work together.

### 💻 Full-Stack Development

We learned how to connect a frontend application with a backend and understand the flow of data between the two layers.

### 🔗 Frontend ↔ Backend Communication

We gained practical experience working with APIs and handling data returned from the backend, including JSON responses consumed by the React application.

### ⚛️ React.js

We strengthened our understanding of component-based frontend development, managing application data, and building interfaces that communicate with backend services.

### 🔥 Laravel

We developed practical experience with Laravel and learned how a backend application can provide data and functionality to a separate frontend.

### 🗄️ Data Management

The project helped us understand how application data is processed on the backend and delivered to the frontend in a structured format.

### 🌿 Git & Collaborative Development

Working together on the same project taught us how to use Git and GitHub for collaborative development, including commits, branches, repository management, and keeping track of changes.

### 🧩 Problem Solving & Debugging

One of the most valuable parts of the project was learning how to investigate problems across different layers of an application — from frontend components to backend logic and API responses.

---

## 🎯 Key Takeaways

AeroTransit helped us understand that building software is not only about writing code.

It is also about:

* Designing clear application architecture
* Connecting independent parts of a system
* Debugging problems across multiple layers
* Writing maintainable code
* Working effectively as a team
* Using version control correctly
* Continuously learning throughout development
